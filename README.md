# Menna's Midnight Birthday Universe

A bilingual Arabic/English birthday microsite for Menna El Sayed Youssef Hassan, styled as a dark pink-and-violet night universe.

## Run locally

Open `index.html` in a modern browser. Keep the `assets` folder alongside it.

## Included

- Animated pink-and-lilac gift welcome screen and flower-burst effect.
- Responsive hero layout designed not to overlap its heading on tablet widths.
- Full-frame portrait slideshow in the hero: a different photo every two seconds.
- Photo wall and a starry galaxy scene with floating photos that cycle in sequence.
- Bilingual birthday messages, interactive letter, rose bouquet, and cake/wish interactions.
- Vinyl-style player with play/pause, previous/next, mute, and seek controls; track names are not exposed.
- Photo lightbox keeps the complete original image inside the viewport.
- Dark, responsive theme with subtle shooting-star accents and a floating back-to-top button.

## Files

- `index.html` — site structure
- `styles.css` — styling and animation
- `script.js` — interactions and photo rotation
- `assets/photos/` — original photos
- `assets/audio/` — birthday track and voice notes

Note: Browsers generally require an initial click before audio can start. The gift-opening click starts the birthday audio.
